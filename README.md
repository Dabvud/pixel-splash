# Pixel Splash

Basketballspiel im Pixel-Look fürs Handy (Hochformat). Aktueller Stand: **Wurf-Labor** – Testseite für die Wurfmechanik (Halten + Wischen, Timing bestimmt die Weite, Richtung das Zielen), alle Werte im Zahnrad-Menü einstellbar.

Live: https://dabvud.github.io/pixel-splash/

```bash
npm install
npm run dev    # lokal starten
npm test       # Tests
npm run build  # Produktions-Build
```
